# Peer-Review Checklist — Chemistry

> Pair with `docs/04-peer-review-blueprint.md` and `templates/review/`. Aim: specific, fair, actionable comments.

## Before accepting
- [ ] No conflict of interest (collaborators, competitors, same institute, financial).
- [ ] Competent for the core claim; enough time to do it properly.

## Reading pass 1 — scope & integrity (10 min)
- [ ] Fits journal scope? Article type correct?
- [ ] Title/abstract match claims; no hype unsupported.
- [ ] Similarity concerns? Data-availability statement present?
- [ ] Ethics statements (human/animal/dual-use) where needed?

## Reading pass 2 — chemistry (30–60 min)
- [ ] Every headline claim supported by data (trace claim → figure/table).
- [ ] Characterisation complete for every new compound (NMR/HRMS/IR/mp/purity).
- [ ] Crystal structures: CCDC numbers, checkCIF, no unexplained A-alerts.
- [ ] Yields reconcile with quantities; purity proof where properties are measured.
- [ ] Controls adequate; alternative mechanisms excluded or discussed.
- [ ] One quantity recomputed by hand; numbers consistent.
- [ ] Key prior work cited (missing key references = major comment).
- [ ] Experimental section reproducible alone.

## Reading pass 3 — presentation (10 min)
- [ ] Figures legible, labelled, units correct, numbered in order.
- [ ] SI organised, complete, cross-referenced.
- [ ] English clarity (never penalise non-native fluency; note ambiguities only).

## Writing the report
- [ ] Summary (3–5 sentences) shows you understood the work.
- [ ] Major comments: numbered, specific, each with *why it matters* + *what to do*.
- [ ] Minor comments: numbered, specific (point to structures/figures by number).
- [ ] No ad hominem; no "must cite my work"; no disproportionate demands.
- [ ] Recommendation + 1–2 sentence justification (Accept / Minor / Major / Reject).
- [ ] Confidential comments to editor only where necessary (ethics, suspected misconduct — via COPE guidelines).

## After submitting
- [ ] Discard manuscript files; maintain confidentiality permanently.
