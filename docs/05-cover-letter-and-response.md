# 05 · Cover Letters & Response to Reviewers

## A. The cover letter (mandatory at every portfolio journal)

**Length:** 1 page. **Audience:** the handling editor, who will desk-reject if novelty/significance isn't instantly clear.

### Structure

1. **Salutation** — "Dear Prof. [Editor name]," (check the journal's current editor-in-chief page — using the wrong name is a red flag).
2. **Submission sentence** — title, article type, journal.
3. **The significance paragraph** (3–6 sentences) — the single most important paragraph:
   - The problem (1–2 sentences, field-level).
   - What you did (1–2 sentences, methods).
   - **What is new and why it matters** (2 sentences — the "so what").
   - Scope fit: "we believe this fits the journal's readership because…"
4. **Declaration sentences** — not published elsewhere, not under consideration elsewhere, all authors approved, no COI (or disclose), (AI-use statement per policy).
5. **Reviewer suggestions** — 3–4 suggested (with e-mail/institution), 0–2 opposed with reasons (Wiley/ACS/RSC all accept this).
6. **Contact** — corresponding author, affiliation, e-mail.

### Don'ts
- Don't over-claim ("revolutionary", "groundbreaking").
- Don't summarise the abstract verbatim — say what it *means*.
- Don't beg ("we would be honoured…") — state value factually.

## B. Response to reviewers (the revision letter)

### Ground rules
- **Reply to every comment** — numbered, matching the reviewer's numbering. Editors count unanswered comments.
- **Two-part answer per comment:** (1) what you did — "We thank the reviewer for this suggestion. We have performed X…"; (2) where — "…see new Figure 5C and the revised text on page 8, lines 12–18."
- Quote changed text or paste it in the letter; mark changes in the manuscript (colour or track changes — then turn tracking OFF before final submission per ACS rule).
- Disagreements: polite, evidence-based. "We respectfully disagree… because [control experiment/data], and we have clarified this in the revised manuscript (p. 6, lines 3–9)." A disagreement with data is acceptable; silence is not.
- Rebut nothing in anger; a reviewer who is wrong can still be right about the need for clarity.

### Structure

```
Response to Reviewers — Manuscript ID XXXXX (R1)
Journal: [name]

We thank both reviewers for their careful reading and constructive comments.
Our point-by-point responses follow. Changes are highlighted in the revised
manuscript (blue text); line numbers refer to the clean version.

REVIEWER 1
R1.1 (comment quoted or paraphrased)
Response: …
R1.2 …

REVIEWER 2
R2.1 …

Summary of changes (optional final block)
- New control experiments: Figures 5C, S12–S14
- 3 new references (refs 34, 41, 52)
- Characterisation data for compounds 7–9 added to SI (pages S8–S11)
```

### Timing
- ACS/RSC/Wiley typical revision windows: **2–6 weeks** (major), faster for minor. Ask for an extension *before* the deadline if needed — editors grant it.
