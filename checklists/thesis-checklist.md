# Thesis Checklist — Chemistry PhD (Indian University Standard)

> Pair with `docs/03-thesis-blueprint.md`. Confirm institute-specific rules with the Academic Office (preliminary-page wording, similarity threshold — typically ≤10% at IISERs).

## A. Preliminary pages (order matters)
- [ ] Title page (institute format + logo, degree, year)
- [ ] Supervisor's certificate
- [ ] Candidate's declaration (+ plagiarism-check statement)
- [ ] Acknowledgements
- [ ] Abstract (250–350 words, standalone)
- [ ] Table of contents (page numbers)
- [ ] List of figures / tables / schemes
- [ ] Abbreviations & symbols (chemistry-complete)

## B. Chapters
- [ ] Chapter 1: introduction, literature review (thematic), gap, objectives, thesis organisation.
- [ ] Results chapters each paper-shaped: intro → results (numbered figures 3.1, 4.2…) → summary.
- [ ] Final chapter: conclusions (numbered, data-backed) + future directions + limitations.
- [ ] Chapter numbers on every figure/table/scheme; every one referenced in text.

## C. Formatting
- [ ] A4; left margin 1.5 in; others 1 in; Times New Roman 12 pt; 1.5 line spacing.
- [ ] Consistent heading hierarchy; chapters start on new pages.
- [ ] Figures ≥300 dpi (structures ≥600 dpi, ChemDraw); equations numbered; page numbers (roman prelims, arabic body).
- [ ] Bibliography one consistent style across all chapters (ACS numbered typical).

## D. Originality & similarity (do this EARLY)
- [ ] Own-papers text reworded in thesis (self-plagiarism check) — cite your own papers.
- [ ] Group-mates' experimental text NOT copied; rewritten + cited.
- [ ] Drafts with version history kept (Overleaf/Git) as authorship evidence.
- [ ] Institute similarity check run on a full draft; flagged passages rewritten; final check ≤10%.
- [ ] Quoted text: short, quoted, cited.

## E. Back matter
- [ ] Appendices (spectra compilations, crystallography tables, coordinates).
- [ ] List of publications (from thesis work) + conference presentations.
- [ ] Reprints/permission notes if reproducing published figures.

## F. Submission pack
- [ ] Searchable PDF (institute convention); source files (LaTeX/Word).
- [ ] Similarity report from the institute's tool.
- [ ] Signed certificates/declarations.
- [ ] Final proofread pass by an outside reader (not your supervisor).
- [ ] Viva preparation: 10-minute presentation of the thesis in one slide each of problem → methods → results (3 chapters) → conclusions; know every figure's numbers.
